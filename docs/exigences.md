# Exigences — Tableau fonctionnel vs technique

| Exigence fonctionnelle | Exigence technique |
|---|---|
| Consulter les films disponibles | Performance : temps de réponse < 2 seconde pour la liste des films |
| Consulter les séances d'un film | Plateforme : application web accessible depuis navigateur desktop et mobile |
| Réserver une place de cinéma | Sécurité : authentification requise avant toute réservation |
| Annuler une réservation | Intégration : API de paiement externe appelée pour confirmer le paiement |
| Gérer les séances (administrateur) | Sécurité : contrôle d'accès réservé au rôle Administrateur |
| Effectuer le paiement en ligne | Performance : paiement traité en < 3 seconde |
| Consulter ses propres réservations | Plateforme : base de données relationnelle pour stocker les réservations |
